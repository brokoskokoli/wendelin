# Handytest WP56: Power-Taste nach Pause (Xiaomi / HyperOS)

1. Einstellungen → Assistent → „Zuverlässig öffnen“ ansehen. Notiere, welche Hinweise stehen.
2. Vorher (Hinweise unverändert): Wendelin per Taskmanager wegwischen, Handy 2 h oder über Nacht liegen lassen, Power-Taste lang drücken. Öffnet Wendelin? Bei Fehlversuch `tool/diag_assistant_idle.sh` laufen lassen (vor dem Drücken starten) und die Ausgabe schicken.
3. Nachher: „Keine Einschränkung erlauben“ bestätigen, Autostart einschalten, Akkusparer auf „Keine Einschränkungen“ (Knopf „Einstellungen des Herstellers öffnen“ bzw. „Akku-Einstellungen öffnen“). Schritt 2 wiederholen (2 h und über Nacht).
4. Beim Start ohne laufenden Prozess erscheint kurz „Wendelin startet …“, danach das Sheet.
5. Rückkehr aus den Systemseiten: Hinweise aktualisieren sich.
