# WP203 MCP: Fehlermeldung des Servers zählt als Inhalt desselben Servers
> Stand: gültig

Voraussetzung: MCP-Server für Smart Home eingerichtet, bei `set_device` „Ohne Nachfrage“ (Stufe A); Websuche an.

- [ ] **Fehler des Servers, dann richtiger Aufruf**: neue Unterhaltung, Gerät mit falschem Namen ansprechen (Server antwortet „Gerät nicht gefunden“), dann den richtigen Namen nennen. *Erwartet*: auch der zweite `set_device`-Aufruf läuft ohne Karte.
- [ ] **Fehler eines anderen Servers**: Tool eines zweiten Servers liefert einen Fehler, danach `set_device`. *Erwartet*: Karte mit Grund „andere Quelle“.
- [ ] **Netzfehler**: Server unerreichbar (WLAN aus/Server aus), Tool schlägt mit Zeitüberschreitung fehl, Netz zurück, dann `set_device`. *Erwartet*: Karte mit Grund (Client-Fehler bleibt fremd).
