# WP201 MCP: Inhalte desselben Servers erzwingen keine Rückfrage
> Stand: gültig

Voraussetzung: MCP-Server für Smart Home eingerichtet (Tools z. B. `list_devices`, `set_device`), bei `set_device` in der Tool-Ansicht „Ohne Nachfrage“ (Stufe A) gewählt; Websuche an; Sicherheitsstufe „Alle Tools bestätigen“ des Servers aus.

- [ ] **Gleicher Server ohne Nachfrage**: neue Unterhaltung, „Welche Geräte gibt es?“, danach „Schalte die Lampe im Wohnzimmer an“. *Erwartet*: `list_devices` und `set_device` laufen ohne Karte; die Lampe schaltet.
- [ ] **Per Tool-Suche**: neue Unterhaltung, Befehl für ein Gerät, das erst über die Tool-Suche gefunden wird. *Erwartet*: auch hier keine Karte (Treffer nur von diesem Server).
- [ ] **Nach Websuche nachfragen, mit Grund**: neue Unterhaltung, „Such im Web nach dem Wetter in Hamburg“, danach „Schalte die Lampe an“. *Erwartet*: Karte für `set_device` mit dem Hinweis „Fragt nach, weil vorher Inhalte aus anderer Quelle gelesen wurden“; ohne Inhalte der Suche in der Karte. „Ja“ führt aus, „Nein“ nicht.
- [ ] **Anderer Server**: zweiter MCP-Server, dessen Tool zuerst liest, danach ein Tool des Smart-Home-Servers. *Erwartet*: Karte mit Grund. Umgekehrt (Smart Home liest, anderer Server schreibt): ebenfalls Karte mit Grund.
- [ ] **Stufe D oder „Alle Tools bestätigen“**: Tool auf „Immer nachfragen“ stellen, Gleicher-Server-Ablauf. *Erwartet*: Karte, **ohne** den Grund (die Stufe fragt, nicht das Fremde).
- [ ] **Fortsetzung**: Gleicher-Server-Ablauf bis nach `list_devices`, App beenden und neu starten, Gespräch fortsetzen, „Schalte die Lampe an“. *Erwartet*: weiter ohne Karte. Nach einer Websuche im selben Gespräch und Neustart: Karte mit Grund.
- [ ] **Neue Unterhaltung**: nach einer Websuche „Neues Thema“, dann Befehl. *Erwartet*: ohne Karte.
- [ ] **Gesperrtes Gerät**: Gerät sperren, Wake Word „Schalte die Lampe an“ nach `list_devices`. *Erwartet*: wie ohne Fremdes (Stufe A läuft). Nach Websuche: „Entsperren“.
- [ ] **Tool-Ansicht**: Server → Tool öffnen. *Erwartet*: „Ohne Nachfrage“ bleibt gewählt und angezeigt, auch nach den Abläufen oben.

## Nicht per Gerät prüfbar
Sitzungssperre (rote Quittung) mit Inhalten desselben Servers bleibt gesperrt: abgedeckt durch `packages/wendelin_tools/test/policy/same_server_test.dart`.
