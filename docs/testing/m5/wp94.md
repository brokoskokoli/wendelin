# WP94 Schnellwechsel des Standard-Agenten (langer Druck auf den Provider-Chip)
> Stand: gültig

Vorbereitung: mindestens zwei Anbieterprofile einrichten (Einstellungen → Anbieter), Hauptbildschirm öffnen, ein kurzes Gespräch führen.

- [ ] **WP94.1 Markierung und Vibration.** Provider-Chip oben gedrückt halten. *Erwartet:* nach etwa einer halben Sekunde erscheint ein blauer Rahmen und eine kurze Vibration (nur, wenn Touch-Vibration im System an ist; mit ausgeschalteter Vibration keine).
- [ ] **WP94.2 Popup nach 2 s.** Weiter halten. *Erwartet:* nach 2 s Gesamtdauer öffnet sich „Agent wechseln“ mit allen Profilen, das aktuelle blau mit Häkchen.
- [ ] **WP94.3 Abbruch.** Nach 1 s loslassen. *Erwartet:* Rahmen verschwindet, kein Popup. Ebenso beim Wegziehen des Fingers.
- [ ] **WP94.4 Auswahl.** Anderes Profil tippen. *Erwartet:* Popup zu, Chat leer, Chip zeigt das neue Profil, Einstellungen → Anbieter markiert es als Standard; die nächste Anfrage geht nur an das neue Profil (ohne Verlauf).
- [ ] **WP94.5 Aktuelles oder Schließen.** Aktuelles Profil tippen oder außerhalb tippen. *Erwartet:* nichts ändert sich, Chat bleibt.
- [ ] **WP94.6 Gesperrt.** Während einer laufenden Antwort den Chip halten. *Erwartet:* weder Markierung noch Popup.
- [ ] **WP94.7 Sprachausgabe.** Während die Antwort vorgelesen wird, wechseln. *Erwartet:* Sprachausgabe stoppt, Chat leer.
- [ ] **WP94.8 TalkBack.** Chip fokussieren, Aktionsmenü. *Erwartet:* Aktion „Agent wechseln“ öffnet das Popup direkt; Zeilen werden mit Name, Stufe und „aktuell“ vorgelesen.
