# WP105 Folgepunkte Audit und Texte

Vorbereitung: Emulator `Wendelin_AOSP_35` (serial `emulator-xxxx`), eine lokale Aufgabenliste (WP88), Spotify-Entwickler-App (WP84) mit Browser im Image.

- [ ] **WP105.1 Audit ohne Aufgabentitel.** „Trag Steuer abgeben morgen als Aufgabe ein“, bestätigen, dann „Hak Steuer ab“. Einstellungen → Protokoll → Eintrag öffnen. *Erwartet:* Bestätigungstext zeigt den Titel ab Zeile 2; im Protokoll (Argumente, Zeile 1) steht kein Titel, nur z. B. `due`/`list`.
- [ ] **WP105.2 Spotify falscher State.** Spotify → **Bei Spotify anmelden**, im Browser nicht fortfahren; stattdessen mit `adb shell am start -a android.intent.action.VIEW -d "app.wendelin://oauth/spotify?code=x\&state=falsch"` eine fremde Antwort schicken, dann ohne Anmeldung zur App zurück. *Erwartet:* Meldung „Anmeldung abgelehnt: Die Antwort von Spotify gehört nicht zu dieser Anmeldung …“ (nicht „Anmeldung abgebrochen“); Browser-Tab einfach schließen ohne fremde Antwort: weiterhin „Anmeldung abgebrochen.“; nichts gespeichert.
- [ ] **WP105.3 Texte in en/fr.** App-Sprache auf Englisch, dann Französisch: Integration (Bring!, Spotify, Todoist, Google Tasks, Home Assistant) in den Fehlerzustand bringen (Flugmodus + Aufruf), **Retry** auf der Kachel und auf der Einrichtungsseite. *Erwartet:* Hinweis in der App-Sprache („… is not reachable …“ / „… injoignable …“), nicht deutsch; Senden-Knopf im Textfeld trägt „Send“/„Envoyer“ als Tooltip.

Die Fehlerzeile der Kachel (pausiert nach Auth-/Antwortfehler) steht in der App-Sprache („<Dienst>: access refused or unexpected answer · paused“); der Bring!-Retry-Hinweis nennt den Ausweg über „Teilen“.

Automatisiert: Unit-Tests je Punkt (`packages/wendelin_integrations/test/audit_task_titles_test.dart`, `spotify/spotify_login_test.dart`, `app/test/settings/reconnect_text_test.dart`, `app/test/settings/spotify_screen_test.dart`); Kotlin `OAuthRedirectTest` (`isForeignState`, `leaveCode`).
