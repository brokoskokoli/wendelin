# WP154 – Sicherheitsstufe je Tool und Home-Assistant-Gerät (Gerätetest)

Lieferung 1 (Stufen, Policy, UI) und Lieferung 2 (Gesperrt-Pfad L2). Sprecher folgt in Lieferung 3 (WP157), bis dahin gilt gesperrt immer „fremde Stimme“. Logik deckt `packages/wendelin_core/test/safety/security_level_test.dart`, `packages/wendelin_tools/test/policy/risk_policy_test.dart`, `packages/wendelin_integrations/test/home_assistant/ha_level_test.dart`, `app/test/settings/security_level_picker_test.dart`. Offen für den Gerätetest (Emulator mit Fake-HA oder echtes HA):

- [ ] **Standard unverändert:** nach dem Update ohne Änderung: „Licht Küche an“ läuft ohne Rückfrage, Rollo (mit früher gesetztem „ohne Rückfrage“) läuft ohne Rückfrage, Schloss/Garage fragen nach. *Erwartet:* wie vor dem Update; in den Einstellungen zeigt das Rollo „Details · Stufe C · geändert“, das Licht „Stufe B · Standard“.
- [ ] **Details eingeklappt:** Einstellungen → Home Assistant → Gerät: unter dem Schalter steht eingerückt „Details · Stufe …“, kleiner als die Schalter; Tippen klappt A–D mit je einer Erklärungszeile auf.
- [ ] **Licht auf D:** Licht auf Stufe D stellen, „Licht an“. *Erwartet:* Bestätigungskarte (`ha__call_secure`). „Standard wiederherstellen“ → wieder ohne Rückfrage.
- [ ] **Rollo C:** Rollo auf C → läuft ohne Rückfrage mit Rückgängig; auf D → fragt.
- [ ] **Schloss bleibt D:** Schloss ohne Änderung → fragt. Auf A oder B stellen → einmal Hinweis „Weniger Schutz?“ mit „Trotzdem ändern“; danach läuft „Haustür aufschließen“ ohne Rückfrage (nur Test, danach „Standard wiederherstellen“).
- [ ] **Tool-Stufe:** Einstellungen → Integrationen → z. B. Kalender/Nachrichten: je Tool „Details“; `external`-Tool auf C → Hinweis, danach ohne Rückfrage; Standard wiederherstellen → fragt wieder.
- [ ] **Gesperrt, Standard (L2):** Gerät sperren, „Taschenlampe an/aus“ → läuft ohne Modell. „Licht Küche an“ → „Bitte entsperre das Telefon“/Entsperren-Dialog, Licht bleibt aus.
- [ ] **Licht A gesperrt (fremde Stimme):** Licht Küche auf Stufe A, Gerät sperren, „Licht Küche an“. *Erwartet:* läuft ohne Entsperren (Modellaufruf nur mit diesem Tool), Antwort kurz; kein Verlauf im Chat nach dem Entsperren. Licht Wohnzimmer (B) bleibt gesperrt.
- [ ] **Rollo C und Schloss D gesperrt:** „Rollo hoch“ und „Haustür aufschließen“ → „Entsperren nötig“, nichts läuft, Fake-HA meldet keinen Aufruf.
- [ ] **Teilerledigung:** Licht A und Schloss D: „Licht Küche an und schließ die Tür auf“. *Erwartet:* Licht geht an, Entsperren wird für den Rest angeboten; nach dem Entsperren läuft nichts zweimal (Licht kein zweites Mal, Schloss wird nicht von selbst aufgeschlossen, der Nutzer sagt den Rest neu).
- [ ] **Nur Schloss D (nichts erledigt):** „Haustür aufschließen“ gesperrt → Entsperren; nach dem Entsperren läuft die gemerkte Anfrage (30 s) und fragt nach der Bestätigung.
- [ ] **Kein Name:** gesperrt „Wie heiße ich?“ (mit Licht A, damit das Modell läuft) → das Modell kennt den Namen nicht.
- [ ] **Taschenlampe D:** Taschenlampe `on` auf D stellen, gesperrt „Taschenlampe an“ → „Bitte entsperre das Telefon“.
- [ ] **Später (L3, WP157):** erkannte Stimme erlaubt B gesperrt (Licht Wohnzimmer), C/D weiter nicht.

Automatisch (Emulator, Fake-HA): `app/integration_test/ha_locked_e2e_test.dart` über `tool/e2e_android.sh integration_test/ha_locked_e2e_test.dart` (startet den Fake-HA selbst); Lauf durch den E2E-Agenten.
