# Arbeitspakete M2 – Sprache und Assistent

**Definition of Done M2 (Konzept):** Der lange Druck auf die Power-Taste öffnet die App (Standard-Assistent), und ein gesprochener Befehl ergänzt eine Notiz im Obsidian-Vault.

Zusätzlich gilt K7 (ohne Google-Dienste): Whisper lokal ist Standard, System-TTS mit automatischem Fallback auf sherpa-onnx-Stimmen, System-Spracherkennung nur wenn vorhanden.

## Pakete und Reihenfolge

```

  WP16 Obsidian-Integration (Dart): VaultPort, Notiz-Tools, Tagesnotiz, Abschnitte, Suchindex (FTS5 in storage)
Welle B (parallel, nach WP15/WP16)
  WP17 Sprach-Plattform (app): sherpa-onnx (Silero VAD + Whisper), Aufnahme 16 kHz, System-TTS + sherpa-Fallback, Modell-Download-UI, Mikrofon-Berechtigung, STT-Fixtures + WER
  WP18 Assistent und Overlay (app + Kotlin): VoiceInteractionService/SessionService, Overlay laut Design, Push-to-talk im Hauptbildschirm, SAF-Vault-Port, Einstellungen Sprache/Assistent
Welle C
  WP20 Lokale System-Spracherkennung (RecognitionService mit Whisper)
  WP19 End-to-End M2: Emulator (Audio aus Datei), Geräte-Testanleitung für den Maintainer, Demo-Anleitung
```
