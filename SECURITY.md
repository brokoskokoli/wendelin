# Security Policy

Wendelin is a voice assistant that can act on your phone (calls, SMS, contacts, smart home) and
sends your requests to a language model provider you choose. Bugs that could let someone else
control these actions or read your data are taken seriously.

## Supported versions

Only the latest release receives security fixes. Releases are published on the
[Releases](https://github.com/brokoskokoli/wendelin/releases) page.

| Version | Supported |
|---|---|
| 0.1.x (latest) | ✅ |
| < 0.1 | ❌ |

## Reporting a vulnerability

**Please do not open a public issue, discussion or pull request for security problems.**

Report privately via GitHub: open the repository's **Security** tab and click
**[Report a vulnerability](https://github.com/brokoskokoli/wendelin/security/advisories/new)**.
Only the maintainers can see the report.

Please include:

- the Wendelin version and your Android version and device;
- a description of the issue and its impact;
- steps to reproduce (attach files to the advisory, never post them publicly);
- any log output, with secrets such as API keys and tokens removed.

What to expect:

- acknowledgement within **7 days**;
- an assessment and, for confirmed issues, a fix plan within **30 days**;
- coordinated disclosure: we publish a GitHub security advisory together with the fixed release and
  credit you unless you prefer to stay anonymous.

This is a volunteer project; there is no bug bounty.
